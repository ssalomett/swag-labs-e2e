# Salome Tusniashvili - ფინალური პროექტი

პროექტი ასახავს ონლაინ მაღაზიის ([saucedemo.com](https://www.saucedemo.com)) ტესტირების სრულ ციკლს Cypress-ის გამოყენებით. 

პროექტის განხორციელებისას გამოყენებულია **Custom Commands** განმეორებადი პროცესების ავტომატიზაციისთვის და **Fixtures** ველების სატესტო მონაცემებით დინამიურად შევსებისთვის.

---

## პროექტის სტრუქტურა

### 1. Custom Commands (`cypress/support/commands.js`)
პროექტის საწყის ეტაპზე შევქმენი ბრძანებები Login, Cart და Checkout ტესტ-ფაილებისთვის:
* `cy.login(username, password)` — ავტორიზაციის პროცესის ავტომატიზაცია.
* `cy.addToCart(productName)` — პროდუქტის კალათაში დამატება.
* `cy.fillCheckout(firstName, lastName, zip) - ავსებს checkout ფორმას და აჭერს Continue-ს

### 2. Fixtures (`cypress/fixtures/`)
პროექტის ამ ეტაპზე შევქმენი სცენარები სატესტო მონაცემებისთვის:
* `users.json` — ავტორიზაციის სცენარებისთვის (`standard_user`, `locked_out_user`, `problem_user` და ა.შ.).
* `checkoutData.json` — ვალიდური და არავალიდური მონაცემები Checkout ფორმის ვალიდაციებისთვის.

### 3. ტესტ-ფაილები (`cypress/e2e/`)
შევქმენი 4 ტესტ-ფაილი ავტორიზაციის, კალათის, ჩექაუთის და სრული E2E სცენარებისთვის:
* **`01-login.cy.js`** — ავტორიზაციის ტესტებში გამოყენებულია Custom Command ბრძანებები.
* **`02-cart.cy.js`** — კალათაში პროდუქციის დამატება/წაშლის და ბეჯის შემოწმების ტესტები.
* **`03-checkout.cy.js`** — ჩექაუთისთვის შექმნილი Fixtures (`checkoutData.json`) გამოყენებულია ჩექაუთის ვალიდაციებისთვის.
* **`04-full-flow.cy.js`** — სრული E2E სცენარი (ლოგინი, პროდუქტის დამატება, ჩექაუთის შევსება და შეკვეთის დადასტურება).
